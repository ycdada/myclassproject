# 测试说明书

## 1. 测试策略

采用分层测试金字塔：

```
        /\
       /  \      2 个 E2E 场景
      /    \
     /------\
    /        \    15 个集成测试
   /  API 集成 \
  /------------\
 /              \
/  40 个单元测试  \
/__________________\
```

## 2. 测试环境

| 组件 | 版本 |
|------|------|
| Python | 3.12 |
| PostgreSQL + pgvector | 16 |
| Redis | 7 |
| Docker Compose | 3.8+ |
| pytest | 8.3 |
| pytest-asyncio | 0.24 |

启动测试环境：
```bash
docker-compose up -d postgres redis
cd backend && pip install -r requirements.txt
```

## 5. 功能测试

### 5.1 对话画像构建

| 步骤 | 操作 | 验证 |
|------|------|------|
| 1 | 发送第一轮对话 | 系统友好回应并提出下一个问题 |
| 2 | 发送"学过C语言和Python，喜欢动手写代码" | 提取 prior_courses, cognitive_style |
| 3 | 发送"在准备实习面试" | 提取 goal="interview" |

| 5 | 第 5 轮对话 | 画像包含至少 5 个维度 |

### 5.2 资源生成

| 步骤 | 操作 | 验证 |
|------|------|------|
| 1 | 选择数组知识点，触发生成 | SSE 进度流式更新 |
| 2 | 检查讲义 | 包含概念定义、代码示例、复杂度分析、常见误区 |

| 5 | 检查代码案例 | Python 运行通过 |
| 6 | 质量报告 | safety_score >= 0.6 |

### 5.3 学习路径

| 步骤 | 操作 | 验证 |

| 2 | 标记复杂度分析为已完成 | 路径状态更新 |
| 3 | 重新规划 | 已完成节点不再出现在活跃路径 |

### 5.4 防幻觉

| 步骤 | 操作 | 验证 |
