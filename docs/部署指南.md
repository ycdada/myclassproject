# 部署指南

## 1. 环境要求

| 组件 | 最低版本 |
|------|---------|
| Docker | 24.0+ |
| Docker Compose | 2.20+ |
| Python (本地开发) | 3.12 |
| Node.js (本地开发) | 20 |

## 2. Docker Compose 部署（推荐）

### 2.1 克隆项目

```bash
git clone git@github.com:ycdada/myclassproject.git
cd myclassproject
```

### 2.2 配置环境变量

```bash
cp .env.example .env
# 编辑 .env 填入科大讯飞星火 API 凭证
vim .env
```

必需配置项：
```bash
SPARK_APP_ID=your_app_id        # 从讯飞开放平台获取
SPARK_API_KEY=your_api_key
SPARK_API_SECRET=your_api_secret
JWT_SECRET_KEY=$(openssl rand -hex 32)
```

### 2.3 启动服务

```bash
# 启动所有服务（PostgreSQL + Redis + MinIO + Backend + Frontend + Nginx）
docker-compose up -d

# 查看启动日志
docker-compose logs -f

# 检查服务状态
docker-compose ps
```

### 2.4 初始化数据库

数据库在 Backend 启动时会自动执行：
1. 创建所有表（SQLAlchemy `create_all`）
2. 播种 DSA 知识点（30 个 topic）
3. 创建 Demo 学生账号（demo_student / demo123）

### 2.5 摄入教材语料（可选）

```bash
# 进入 backend 容器
docker-compose exec backend bash

# 执行摄入脚本（需等待 embedding 模型下载 ~500MB）
python -m app.scripts.ingest_textbook
```

### 2.6 访问系统

| 服务 | 地址 |
|------|------|
| 前端 SPA | http://localhost:3000 |
| 后端 API | http://localhost:8000 |
| API 文档 (Swagger) | http://localhost:8000/docs |
| MinIO 控制台 | http://localhost:9001 |

## 3. 本地开发部署

### 3.1 启动基础设施

```bash
# 仅启动数据库和缓存
docker-compose up -d postgres redis minio
```

### 3.2 启动后端

```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 3.3 启动前端

```bash
cd frontend
npm install
npm run dev
# 或使用演示模式
NEXT_PUBLIC_DEMO_MODE=true npm run dev
```

## 4. 生产部署（参考）

```bash
# 构建生产镜像
docker-compose -f docker-compose.prod.yml build

# 启动
docker-compose -f docker-compose.prod.yml up -d
```

生产环境额外建议：
- 修改 `JWT_SECRET_KEY` 为强随机字符串
- 配置 HTTPS 证书（通过 Nginx + Let's Encrypt）
- 设置 `DEBUG=false`
- 配置 PostgreSQL 数据库备份
- 使用外部 MinIO 或 S3 替代本地存储

## 5. 故障排查

| 现象 | 可能原因 | 解决方案 |
|------|---------|---------|
| Backend 启动失败 | 数据库未就绪 | `docker-compose restart backend` |
| 星火 API 调用失败 | 额度不足 / 凭证错误 | 检查 .env 配置；使用演示模式 |
| pgvector 扩展缺失 | PostgreSQL 镜像不是 pgvector 版本 | 使用 `pgvector/pgvector:pg16` 镜像 |
| 前端 SSE 无响应 | 后端未启动 | 检查 `docker-compose logs backend` |
| 嵌入模型下载慢 | 首次加载需下载 500MB | 等待或配置镜像源 |
| 端口冲突 | 3000/8000/5432 已被占用 | 修改 `docker-compose.yml` 端口映射 |

## 6. 停止与清理

```bash
# 停止服务
docker-compose down

# 停止并清理数据卷
docker-compose down -v
```
