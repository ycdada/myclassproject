# 演示视频脚本（7分钟）

## 时间分配

| 段落 | 时长 | 内容 |
|------|------|------|
| 开场 | 30s | 项目介绍 |
| 功能1 | 90s | 对话式学习画像构建 |
| 功能2 | 90s | 多智能体协同资源生成 |
| 功能3 | 60s | 个性化学习路径规划 |
| 功能4 | 60s | 智能辅导（加分项） |
| 功能5 | 45s | 学习效果评估（加分项） |
| 总结 | 30s | 创新点回顾 |
| 备用 | 15s | 过渡/调整 |

---

## 详细脚本

### 0:00 - 0:30 开场：项目介绍

**画面**：DSALearn 首页/学习看板
**旁白**：
> 大家好，我们展示的是「DSALearn」——基于大模型的个性化资源生成与学习多智能体系统。针对数据结构与算法课程，我们构建了 9 个协同 AI 智能体，实现从画像构建、资源生成、路径规划到智能辅导的全流程个性化学习体验。

**展示要点**：
- 首页统计卡片（已学知识点、生成资源数、练习正确率、学习时长）
- 快速操作入口

---

### 0:30 - 2:00 功能1：对话式学习画像构建

**画面**：登录 → 进入 AI 对话页 → 开始对话
**旁白**：
> 首先，学生通过与 AI 助手的自然语言对话，系统自动提取学习画像。这里我们以一名准备实习面试的同学为例。

**演示操作**：
1. 打开登录页，演示模式一键登录
2. 进入 AI 对话页
3. 第1轮：系统询问编程背景 → 学生回答"学过C和Python，算法较薄弱"
4. 第2轮：系统询问学习偏好 → 学生回答"喜欢看视频后动手写代码"
5. 第3轮：系统询问学习目标 → 学生回答"准备明年实习面试"

**画面**：画像更新提示（profile_update 事件）
**旁白**：
> 系统通过星火大模型的 Function Calling 能力，从对话中自动提取 8 个维度的画像特征，包括认知风格、知识基础、易错领域、学习目标等。所有画像版本化管理，支持动态更新。

**展示要点**：
- SSE 流式输出效果（逐字显示）
- 画像维度提取结果

---

### 2:00 - 3:30 功能2：多智能体协同资源生成

**画面**：进入学习资源页 → 选择"数组"知识点 → 点击生成
**旁白**：
> 接下来是系统的核心功能——多智能体协同资源生成。我们选择"数组"这个知识点来展示。系统通过 LangGraph 编排 9 个智能体协同工作。

**演示操作**：
1. 进入资源页面
2. 筛选"课程讲义"，查看已生成的数组讲义
3. 点击查看 → Markdown 渲染 + LaTeX 公式 + 代码高亮
4. 切换到"思维导图"，查看 Mermaid 可视化
5. 切换到"练习题"，展示 5 种题型
6. 切换到"代码案例"，展示可运行的 Python 代码

**画面**：资源生成 SSE 进度流
**旁白**：
> 系统依次调用 Content Generator 生成讲义、Exercise Designer 生成练习题、Code Mentor 生成代码示例（并经过沙箱验证）、Multimedia Creator 生成思维导图，最后由 Assessor Agent 进行质量把关。

**展示要点**：
- 讲义：概念定义、伪代码、复杂度分析、常见误区（Markdown + LaTeX）
- 思维导图：Mermaid.js 可视化知识结构
- 练习题：选择题/判断题/简答题/填空题/编程题，渐进式提示
- 代码案例：Python 代码，经沙箱验证可运行

---

### 3:30 - 4:30 功能3：个性化学习路径规划

**画面**：进入学习路径页
**旁白**：
> 系统基于 DSA 知识图谱和学生的个人画像，自动规划个性化学习路径。我们设计了 4 种路径策略。

**演示操作**：
1. 查看当前学习路径（时间线样式）
2. 展示已完成节点（绿色✓）和当前学习节点（蓝色▶）
3. 点击"重新规划"按钮
4. 展示更新后的路径

**画面**：知识图谱结构示意
**旁白**：
> DSA 知识图谱包含 30 个知识点，覆盖从基础到进阶的完整课程体系。系统通过拓扑排序算法，结合学生的掌握度、学习目标、学习节奏，动态规划最优路径。评估未通过时自动插入补救节点，评估优异时自动加速。

**展示要点**：
- 时间线样式路径视图
- 已完成/学习中/可学习/待解锁 四种状态
- 每个节点的难度星级和预估时间

---

### 4:30 - 5:30 功能4：智能辅导（加分项）

**画面**：进入 AI 对话页（辅导模式）→ 提问
**旁白**：
> 当学生在学习过程中遇到问题，可以使用智能辅导功能。系统提供文字讲解、图解和语音等多种形式的解答。

**演示操作**：
1. 提问："什么是二叉搜索树的删除操作？"
2. 系统流式输出文字解释
3. 自动附加代码示例
4. 展示 Mermaid 图解

**画面**：多模态响应
**旁白**：
> 辅导 Agent 通过 RAG 检索相关知识，利用星火大模型生成文字解释。对于代码问题，自动调用 Code Mentor 提供可运行的示例。对于概念问题，生成 Mermaid 图解帮助理解。语音讲解通过讯飞 TTS 合成。

**展示要点**：
- SSE 流式文字输出
- 代码块实时展示
- 图解生成
- 多种回答形式整合

---

### 5:30 - 6:15 功能5：学习效果评估（加分项）

**画面**：进入评估报告页
**旁白**：
> 系统通过实时追踪学习行为、练习测试情况和资源使用反馈，实现多维度学习效果评估。

**演示操作**：
1. 展示评估报告页面
2. 整体掌握度、学习进度、投入度、学习速度 四维卡片
3. 知识点掌握度柱状图
4. 优势领域和待提升领域
5. 学习建议卡片

**画面**：Dashboard 数据
**旁白**：
> 基于评估结果，系统自动调整学习路径和资源推送策略。低掌握度的知识点会自动加入补救路径，高质量资源会优先推荐。整个评估是动态、持续优化的过程。

**展示要点**：
- 掌握度可视化（进度条）
- 优劣势分析
- 个性化建议（复习某知识点、做某类练习）

---

### 6:15 - 6:45 总结：创新点回顾

**画面**：系统架构图 + 创新点列表
**旁白**：
> 最后回顾本系统的核心创新点：

> 第一，图谱驱动的智能体编排——DSA 知识图谱不仅是课程骨架，还作为 Agent 协作的拓扑结构，实现知识导航与智能路由的统一。

> 第二，质量把关架构——每个生成资源在交付前经过独立的 Assessor Agent 审查，包括内容安全过滤、DSA 事实校验和代码沙箱验证。

> 第三，脚本式多模态生成——不直接生成视频/图片，而是生成可确定性渲染的脚本（Mermaid、Manim），确保输出质量和可验证性。

> 第四，渐进式画像构建——通过对话初建、诊断校准、行为追踪三阶段构建动态画像，版本化管理。

**展示要点**：
- 架构图（前端→API网关→编排层→AI层→数据层）
- 4 个创新点列表

---

### 6:45 - 7:00 结尾

**画面**：系统 Logo + 团队信息（可选）+ GitHub 地址
**旁白**：
> 感谢观看！DSALearn 展示了如何借助大模型技术和多智能体架构，实现真正个性化、高质量的学习体验。本项目基于科大讯飞星火大模型开发。

## 录制注意事项

1. **画面清晰度**：1920×1080 或以上
2. **鼠标操作**：使用鼠标高亮/圈选效果突出操作位置
3. **网速**：预先生成核心资源，避免演示时等待
4. **备用方案**：开启演示模式（`NEXT_PUBLIC_DEMO_MODE=true`），确保即使 API 不可用也能完整演示
5. **过渡效果**：页面切换使用平滑过渡（1-2秒）
6. **字幕**：建议添加中文字幕
