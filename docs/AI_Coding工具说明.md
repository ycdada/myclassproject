# AI Coding 工具使用说明

## 使用的 AI 工具

本项目开发过程中使用了以下 AI 辅助编程工具：

| 工具 | 提供商 | 用途 |
|------|--------|------|
| **Claude Code** (Opus 4.8) | Anthropic | 架构设计、代码实现、文档生成、测试编写 |
| **科大讯飞星火大模型** | 科大讯飞 | 系统核心 LLM 服务（文本生成、对话、Function Calling） |

## AI 辅助环节

### 1. 系统架构设计
- **输入**：赛题需求文档
- **AI 输出**：分层架构图、技术栈选型、多智能体协同框架设计
- **人工审查**：对比赛题要求逐项确认，调整技术选型适配科大讯飞生态

### 2. 后端代码实现
- **智能体编排器** (`agents/orchestrator.py`)：LangGraph StateGraph 图结构、9 个节点路由逻辑
- **星火 API 客户端** (`services/spark_client.py`)：WebSocket HMAC-SHA256 认证、流式对话
- **RAG 管道** (`services/rag_service.py`)：pgvector 检索、嵌入模型集成
- **DSA 知识图谱** (`knowledge_graph/`)：30+ 知识点、拓扑排序、路径规划算法
- **安全模块** (`safety/`)：防幻觉检查、内容过滤、代码沙箱
- **人工审查**：所有 LLM 调用的 prompt 模板人工调整、错误处理路径补充、竞赛特殊要求适配

### 3. 前端代码实现
- **页面组件**：6 个主要页面（学习看板、AI 对话、资源浏览、学习路径、练习中心、评估报告）
- **API 客户端**：REST + SSE 双模式、Mock 数据降级
- **状态管理**：Zustand Store
- **人工审查**：UI 布局调整、交互逻辑优化、移动端响应式适配

### 4. 文档生成
- API 密钥配置指南
- 系统开发说明书（本文档集的一部分）
- 测试说明书
- 部署指南
- AI Coding 工具说明（本文档）

### 5. 教材语料
- 12 篇 DSA 教材 Markdown（`knowledge_graph/textbook/`），覆盖 30+ 知识点
- 人工审查：内容准确性校验、LaTeX 公式修正、代码示例测试

## 人工修改说明

所有 AI 生成的代码均经过以下人工处理：

1. **代码审查**：逐文件审查逻辑正确性、边界条件处理
2. **Prompt 优化**：所有 LLM 调用的系统提示词经人工设计，确保输出质量
3. **竞赛适配**：确保所有外部依赖符合开源协议要求、使用科大讯飞 AI 工具
4. **安全加固**：补充防幻觉策略、内容安全过滤机制
5. **错误处理**：添加 API 调用失败降级、网络异常处理
6. **Mock 数据层**：独立设计演示模式数据结构，确保无 API 也能完整演示
