# 复杂度分析

## 时间复杂度

时间复杂度衡量算法执行时间随输入规模增长的变化趋势，使用大O表示法描述。

### 大O表示法

大O表示法描述算法运行时间的上界（最坏情况）。例如：
- $O(1)$ — 常数时间，执行时间与输入规模无关
- $O(\log n)$ — 对数时间，每次操作将问题规模减半
- $O(n)$ — 线性时间，执行时间与输入规模成正比
- $O(n \log n)$ — 线性对数时间，常见于高效排序算法
- $O(n^2)$ — 平方时间，常见于嵌套循环
- $O(2^n)$ — 指数时间，常见于穷举搜索

### 常见操作复杂度

| 数据结构 | 访问 | 搜索 | 插入 | 删除 |
|---------|------|------|------|------|
| 数组 | $O(1)$ | $O(n)$ | $O(n)$ | $O(n)$ |
| 链表 | $O(n)$ | $O(n)$ | $O(1)$ | $O(1)$ |
| 二叉搜索树(平衡) | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ |
| 哈希表 | - | $O(1)^*$ | $O(1)^*$ | $O(1)^*$ |

*哈希表操作是平均时间复杂度，最坏情况可退化为 $O(n)$。

### 递归算法复杂度分析

使用**主定理**（Master Theorem）分析分治递归：
$$
T(n) = a \cdot T\!\left(\frac{n}{b}\right) + f(n)
$$

三种情况：
1. 若 $f(n) = O(n^{\log_b a - \epsilon})$，则 $T(n) = \Theta(n^{\log_b a})$
2. 若 $f(n) = \Theta(n^{\log_b a})$，则 $T(n) = \Theta(n^{\log_b a} \log n)$
3. 若 $f(n) = \Omega(n^{\log_b a + \epsilon})$ 且满足正则条件，则 $T(n) = \Theta(f(n))$

## 空间复杂度

空间复杂度衡量算法执行所需的额外存储空间。

### 常见空间复杂度
- $O(1)$ — 原地算法，只使用常量额外空间
- $O(n)$ — 需要与输入规模成正比的额外空间
- $O(\log n)$ — 递归调用栈深度

### 原地算法示例

```python
def reverse_array(arr):
    """原地反转数组，空间复杂度 O(1)"""
    left, right = 0, len(arr) - 1
    while left < right:
        arr[left], arr[right] = arr[right], arr[left]
        left += 1
        right -= 1
```

## 均摊分析

均摊分析关注一系列操作的平均代价，而非单个操作的最坏情况。

### 聚合分析
动态数组扩容：当数组满时，分配2倍大小空间并复制元素。单次扩容是 $O(n)$，但 $n$ 次插入的总代价为 $O(n)$（因为扩容次数为对数级别），均摊 $O(1)$。

### 记账方法
为每次操作分配"均摊代价"：
- 廉价操作多收"费用"存为"信用"
- 昂贵操作使用之前积累的"信用"支付

## 常见误区

- **误区**：时间复杂度越低越好，忽略常数因子。
  **正确**：对于小规模数据，$O(n^2)$ 且常数小的算法可能快于 $O(n \log n)$ 但常数大的算法。

- **误区**：递归算法的时间复杂度一定比迭代高。
  **正确**：通过尾递归优化和记忆化，递归可以具有与迭代相同的时间复杂度。

- **误区**：混淆最坏情况和平均情况复杂度。
  **正确**：例如快速排序最坏 $O(n^2)$ 但平均 $O(n \log n)$，且实际中很少遇到最坏情况。
